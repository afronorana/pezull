pezull

Hover effects for touch screens. Scroll, and whatever reaches the middle of the screen acts hovered.

On a computer, hover with your mouse, or turn on the active area below and scroll.

  1. Fill

    A colour sweeps in behind the card.

    Spring timetable
    Ferries to Sarandë, every two hours
    @container style(--pezull: 1) {
  .stage::before { transform: scaleX(1); }
}

  2. Underline

    A link announces itself before it is tapped.

    Read the full guide
    @container style(--pezull: 1) {
  strong { background-size: 100% 3px; }
}

  3. Reveal

    Details that would appear on hover open up instead.

    Byrek me spinaq

    Spinach and gjizë in hand-stretched pastry. Baked every morning, gone by noon.

    @container style(--pezull: 1) {
  .more { grid-template-rows: 1fr; }
}

  4. Lift

    The card rises off the page.

    Theth, 3 nights
    Guesthouse with breakfast and a mountain guide
    @container style(--pezull: 1) {
  .stage { transform: translateY(-6px); }
}

  5. Swap

    Discrete properties like visibility switch too.

    Tap to add to basketAdded once you tap
    @container style(--pezull: 1) {
  .before { visibility: hidden; }
  .after { visibility: visible; }
}

  6. On the element itself

    Style queries reach children. For the .pezull element itself, use --pezull as a number.

    Fades in while centred
    .pezull { opacity: calc(0.35 + var(--pezull) * 0.65); }

Use it

Load the stylesheet and the fallback for older browsers:

<link rel="stylesheet" href="https://unpkg.com/pezull@2/pezull.css">
<script type="module">
  import pezull from 'https://unpkg.com/pezull@2/pezull.js';
  pezull();
</script>

Add class="pezull" to an element and style its children inside @container style(--pezull: 1). Options, browser support and an install prompt for coding agents are in the README.
